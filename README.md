# Smart Complaint Management System (SCMS)

## Overview

Smart Complaint Management System (SCMS) is a full-stack web application designed to simplify complaint registration, tracking, assignment, and resolution. The platform enables users to raise complaints, monitor real-time updates, and receive notifications while allowing administrators and staff to efficiently manage complaint workflows through dashboards and role-based access control.

---

## Features

### User Module
- Secure user registration and login
- JWT-based authentication
- Create and track complaints
- View complaint history
- Receive notifications
- Manage profile details
- Change and reset password

### Staff Module
- View assigned complaints
- Update complaint status
- Add resolution details
- Manage complaint workflow

### Admin Module
- Admin dashboard with complaint statistics
- Manage users and roles
- Assign complaints to staff
- Manage categories and priorities
- Monitor complete complaint lifecycle
